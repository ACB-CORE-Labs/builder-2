# deepagents Forge profile templates

These YAML files are passive Forge templates. They are examples of governed
deepagent profile shapes and are not runtime authority.

They do not construct deepagents, start Goose, call models, invoke MCP/tools,
execute shell commands, write target source, mutate git, or promote profiles.
Any future runtime use requires a separate governed candidate, HITL approval,
verification evidence, and command-authority path.
